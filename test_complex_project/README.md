# test_complex_project

A Roast project.

## Getting Started

```bash
# Build the project
roastc build

# Run the project
roastc run src/main.roast

# Run tests
roastc test
```

## Project Structure

```
test_complex_project
├── roast.toml      # Project configuration
├── src/
│   └── main.roast    # Source files
└── tests/
    └── test_main.roast  # Test files
```
